# OpenCode local session rename

This plugin listens for OpenCode V2 `session.execution.succeeded` events (and the legacy `session.idle` event) and names root sessions from user/assistant text; child sessions are ignored. It asks for a natural title of at most 30 Unicode codepoints that captures both the conversation topic and latest progress/status; this is semantic compression, not hard truncation. If the first candidate is empty, overlong, or clearly explanatory, it makes at most one additional local rewrite request. If that also fails validation, the existing title is left untouched. It tracks V2 execution start/failure events to avoid naming a conversation while it is running. Context preserves a short initial user topic alongside recent conversation text within the existing small context budget. Generation uses only Ollama's loopback `http://127.0.0.1:11434/api/generate` endpoint and defaults to `qwen2.5:0.5b`. There is no cloud fallback or API fee; local inference still consumes hardware power. Requests set `keep_alive: 0` to release the model after use. This minimizes idle memory but makes cold starts noticeably slower (the first locally measured run took about 51 seconds); the request timeout is 120 seconds to accommodate cold startup. The small model may produce weak or inaccurate titles, and the bounded rewrite is not guaranteed to fix them; this plugin intentionally does not download or switch to a larger model automatically.

No cloud model configuration is needed. To test this package, run `npm test`.

The plugin also exposes the `local-session-rename` V2 RPC (`getState` plus a live `state` event), keyed by the public execution event's stable top-level `id` so a late result cannot release another execution's notification. The Omarchy notification plugin uses this contract to delay only completion notifications until renaming reaches a terminal result; keep both plugins loaded in the same OpenCode server. Notifications still proceed if the rename plugin/RPC is unavailable or its bounded wait expires.
